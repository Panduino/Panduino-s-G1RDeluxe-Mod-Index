# Panduino's G1R Deluxe Mod Index

A small index for my released G1R Deluxe mods.

## Add it to G1R Deluxe

In the launcher, open **Find Mods** and add this source:

```
Panduino/Panduino-s-G1RDeluxe-Mod-Index
```

The index points to the GitHub releases for each mod. It does not contain the mods themselves.

## Mods

- Battle Effect Colors
- Choose Your Avatar
- Alternate Oak Intro
- Gen 3 Ball Rarity
- Mew Under the Truck
- Level Up Evolutions Gen 3
- Navel Rock + Birth Island Restoration
- Darkrai + Cresselia Events

New releases are picked up automatically by the index refresh.
