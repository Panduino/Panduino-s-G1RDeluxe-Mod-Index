# MJ's (Panduino) G1R Deluxe Mod Index

A small index for my released G1R Deluxe mods.

## Add it to G1R Deluxe

In the launcher, open **Find Mods** and add this source:

```
Panduino/Panduino-s-G1RDeluxe-Mod-Index
```

The index points to the GitHub releases for each mod. It does not contain the mods themselves.
